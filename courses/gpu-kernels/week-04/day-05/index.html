Implement Blockwise Causal Attention Reference

By the end of this hour

  • Apply the verified recurrence to blockwise causal self-attention.
  • Avoid constructing a full sequence-by-sequence score tensor.

Before you begin

  • The passing online-softmax reference and the supplied dense causal-attention reference in fixtures/decoder.py.
  • Small local Q/K/V tensors with one head and a fixed value dimension.

Environment or workflow question? Day 0 handbook.

The key idea

For a query block QbQ_bQb​, compute only one score tile QbKt⊤/DQ_bK_t^\top/\sqrt{D}Qb​Kt⊤​/D​ at a time. Each query row owns its own running maximum, denominator, and weighted output vector. Causal masking uses absolute positions: key position j is valid only when j is at most query position i. Query and key block numbers alone are insufficient for positions inside a diagonal tile. The output accumulator spans query-block rows by value dimension, while score storage spans query-block rows by key-block rows. Keeping these tiles bounded avoids allocating the full quadratic score matrix.

Your 60-minute plan

  1. Retrieve

    5 min

    For query positions 4 through 7 and key positions 4 through 7, draw the valid causal entries and identify the diagonal.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read K4’s blockwise attention dataflow and causal masking description. Relate each running state to one query row.

  3. Build

    35 min

    Extend your PyTorch reference to Q, K, and V shaped N by D, starting with one head and no dropout. Loop over query blocks and key blocks, compute scaled scores, mask using absolute i and j, and update the verified online state per row. Skip key tiles entirely beyond the query block’s causal range; initialize safely for any row with no valid values in a tile. Compare lengths such as 4 and 8 with block sizes 2 and 4 against dense causal attention. Inspect allocations in your code to ensure no N by N score tensor is retained.

  4. Verify and save

    10 min

    Save output errors and a diagonal-tile mask example. Confirm the implementation builds only score tiles and per-query running state, not a list of all tiles.

What to save

Small causal attention outputs agree with the dense reference.

Watch for: Appending every temporary score tile to a debug list recreates quadratic storage even if the main loop is blockwise.
