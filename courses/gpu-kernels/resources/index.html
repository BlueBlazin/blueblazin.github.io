Extended paper & project catalog

GPU kernels and optimization

  • **K1 — GPU MODE lecture materials.** Select profiling, CUDA execution, GPU memory, reductions, Triton, and FlashAttention topics. Skip unrelated lectures until needed.
  • **K2 — CUDA C++ Best Practices.** Use memory access, timing, occupancy, and precision sections while interpreting your own profiles.
  • **K3 — Official Triton tutorials.** Work through vector addition, fused softmax, matrix multiplication, normalization, and fused attention in that order, implementing before comparing with reference code.
  • **K4 — FlashAttention and FlashAttention-2.** Derive IO savings and online softmax; implement the restricted forward exercise. The official repository provides current hardware constraints.
  • **K5 — PyTorch custom Triton integration.** Study torch.library.triton_op, composition with compile, and autograd registration. Use the guidance matching your pinned version.
  • **K6 — Pallas GPU quickstart, Pallas overview, and Hopper pipelined matmul.** Use actual H100 execution and the documented Mosaic GPU programming model.
  • **K7 — FlashAttention-4, author engineering article, and CuTe DSL quickstart.** Read hardware bottleneck shifts and a code example. FlexAttention with FA4 is optional because the integration's compatible versions can be fast-moving.
  • **K8 — Helion and KernelBench.** Optional continuation: compare a higher-level kernel DSL, or let your agent propose kernels in a correctness-gated isolated worker. Keep evaluator/reference code outside the candidate's writable area and recompute baselines on your hardware.
