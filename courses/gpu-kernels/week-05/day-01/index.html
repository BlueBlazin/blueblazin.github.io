Environment or workflow question? Day 0 handbook.

The key idea

Each program keeps the query tile and updates a separate m, l, and weighted accumulator for every query row. A K tile produces scaled scores; their maximum determines a rescaling of prior state before the new probabilities contribute. The probability tile times V updates the FP32 weighted accumulator, and division by l occurs before storing output. Because this combines two matrix products, reduction state, and masks, debugging everything at once is expensive. Begin with one exact tile and finite moderate inputs. Preserve the recurrence’s scale convention consistently if adapting tutorial code that uses a different exponential base.

Your 60-minute plan

  1. Retrieve

    5 min

    Write the m, l, and weighted-accumulator updates from memory. Identify every place alpha rescales old state.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Inspect only the required K3 forward code. Match your pinned version’s dot and exponential conventions to the K4 recurrence before implementation.

  3. Build

    35 min

    Create kernels/triton_attention.py with a wrapper enforcing the frozen contract. Translate Q/K/V addressing and per-query FP32 state from your verified reference. Implement the key-tile loop, scaled scores, causal diagonal mask, maximum rescaling, denominator update, and probability-times-V accumulator update. Start with one exact query/key tile at B=H=1, D=32 and modest finite values. Compare the complete output against both dense and blockwise references. Use small targeted state/debug outputs only if needed, removing them before timing. Keep all other shape cases rejected until they are validated.

  4. Verify and save

    10 min

    Save the exact input configuration, maximum output error, and reproduction command. If incorrect, record the first divergent stage rather than proceeding to benchmarking.

What to save

What must change if an implementation uses exp2 instead of exp?
