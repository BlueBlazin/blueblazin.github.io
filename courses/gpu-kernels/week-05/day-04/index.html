Derive RMSNorm Input and Weight Gradients

By the end of this hour

  • Derive both RMSNorm gradients with correct axes.
  • Validate the derivative independently of GPU precision.

Before you begin

  • Your RMSNorm forward formula and supported shape contract.
  • A small PyTorch CPU reference using explicit epsilon.

Environment or workflow question? Day 0 handbook.

The key idea

For one row x of width D, define r = (mean(x²) + ε)^(-1/2), y = w ⊙ x r, and upstream gradient g = ∂L/∂y. The input gradient is r(g ⊙ w) − x r³ mean(g ⊙ w ⊙ x). The shared weight gradient sums g ⊙ x r over every leading row dimension. The correction term couples all elements in a row. Epsilon remains inside r; replacing mean(x²) by a variance would derive a different operator. This algebra check is separate from validating the eventual low-precision GPU implementation.

Your 60-minute plan

  1. Retrieve

    5 min

    Write the RMSNorm forward equation and identify the normalized axis without opening your code.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read K3 normalization backward reasoning. Mark which LayerNorm terms are absent from RMSNorm; do not copy its derivative unchanged.

  3. Build

    35 min

    Create a scratch derivation beside your existing normalization tests. Flatten leading dimensions into M rows and annotate every intermediate with its shape. Derive dx using the product rule and dr/dx, then derive dw by summing row contributions. Implement these equations with ordinary FP64 CPU tensor operations for a tiny M=2, D=5 example. Form the scalar objective sum(y*g) with a fixed random g and compare your equations with PyTorch autograd. Repeat with all-zero x and a nonzero epsilon; retain the reference for later GPU comparisons.

  4. Verify and save

    10 min

    Save dimensioned equations and maximum absolute errors for dx and dw, including the zero-input case. No cloud GPU is needed.

What to save

Dimensioned backward equations and a validated reference.

Watch for: Using the LayerNorm mean-subtraction derivative for RMSNorm.

Check your understanding

Why is dw reduced over rows but dx corrected over features?

Check your reasoning

The same weight vector is reused across rows, while each row has its own normalization statistic.
