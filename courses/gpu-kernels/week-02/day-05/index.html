Specify RMSNorm Precision and Shapes

By the end of this hour

  • Specify RMSNorm’s formula, epsilon, precision, and layouts.
  • Build reference examples before implementing the GPU reduction.

Before you begin

  • The framework rmsnorm_reference function supplied in fixtures/decoder.py; no architecture-course implementation is required.
  • The row-reduction lessons from Triton softmax.

Environment or workflow question? Day 0 handbook.

The key idea

RMSNorm scales each row x by the reciprocal square root of its mean square plus epsilon, then multiplies by a learned vector w: yi=xiwi/1N∑jxj2+εy_i=x_iw_i/\sqrt{\frac{1}{N}\sum_j x_j^2+\varepsilon}yi​=xi​wi​/N1​∑j​xj2​+ε​. Unlike LayerNorm, it does not subtract a row mean. For an M by N input, the reduction yields M scalars and the weight has N entries shared across rows. Accumulating squares in FP32 reduces avoidable error when inputs are lower precision. Epsilon and the point where casts occur are part of the operation definition, so reference and custom implementations must agree on them.

Your 60-minute plan

  1. Retrieve

    5 min

    Write RMSNorm from memory and identify which axis is reduced. Explain the role of epsilon for a zero row.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Use K3’s normalization tutorial for row-reduction and accumulation patterns; adapt the pattern to RMSNorm rather than copying LayerNorm’s mean subtraction.

  3. Build

    35 min

    Create notes/kernels/rmsnorm-contract.md. Specify contiguous M by N inputs, a contiguous length-N weight, epsilon such as 1e-6, and FP32 accumulation. Begin with FP32 inputs; declare FP16 as a later supported test only if the environment handles it. Choose row counts 1, 7, and 64 with widths 1, 31, 32, 33, 127, and 128. Write a reference that casts before squaring and casts the final result deliberately. Calculate zero and constant-row cases by hand and save expected values alongside the shape matrix.

  4. Verify and save

    10 min

    Check the reference against hand calculations, including a non-unit weight vector. Save epsilon, accumulation dtype, output dtype, and layout rules in one contract.

What to save

Explicit supported-shape contract and reference calculations.

Watch for: Copying a LayerNorm tutorial’s mean subtraction would implement a different operator.

Check your understanding

What happens to an all-zero row when epsilon is positive?

Check your reasoning

Its normalized output remains zero; epsilon keeps the reciprocal square root finite.
