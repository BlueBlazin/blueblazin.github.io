Derive Stable Row Softmax

By the end of this hour

  • Derive stable row softmax and its reduction dimensions.
  • Freeze a small support and correctness matrix before writing the kernel.

Before you begin

  • Your Triton vector-add kernel and timing utility.
  • A CPU or MPS PyTorch environment; a cloud GPU is unnecessary today.

Environment or workflow question? Day 0 handbook.

The key idea

For a row xxx, stable softmax computes:

softmax⁡(x)i=exi−m∑jexj−m,m=max⁡jxj.\operatorname{softmax}(x)_i=\frac{e^{x_i-m}}{\sum_j e^{x_j-m}},\qquad m=\max_j x_j.softmax(x)i​=∑j​exj​−mexi​−m​,m=jmax​xj​.

Subtracting one shared constant leaves the mathematical probabilities unchanged and avoids exponentiating large positive values. For an M by N input, the maximum and denominator each have one value per row. A fused row kernel can keep these intermediates on chip and write only the final output. Its ideal payload is one input read plus one output write; that estimate does not imply every row width fits the same execution strategy.

Your 60-minute plan

  1. Retrieve

    5 min

    From memory, derive why subtracting a common constant cancels between the numerator and denominator.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read K3’s fused-softmax explanation of reductions, power-of-two blocks, and global-memory traffic. Focus on the algorithm before copying code.

  3. Build

    35 min

    Create notes/kernels/softmax-contract.md and a small FP32 reference function. Declare contiguous two-dimensional finite inputs, row-wise normalization, and an initial maximum width such as 1024. Define fixed shapes including widths 1, 31, 32, 33, 127, 128, and 129 and row counts 1 and 17. Add zeros, repeated values, and large finite positive/negative offsets. Write the stable formula with M by N shapes and estimate ideal fused traffic as 2MN times element bytes. Keep nonfinite inputs explicitly outside the initial contract.

  4. Verify and save

    10 min

    Check each reference row sums approximately to one and is unchanged by a finite common offset within numerical tolerance. Save the contract and test vectors.

What to save

Stable formula, bytes estimate, and a fixed correctness matrix.

Watch for: An all-negative-infinity row is outside this finite-input contract; do not silently claim it behaves like an ordinary row.

Check your understanding

Why does max subtraction help without changing softmax mathematically?

Check your reasoning

The common factor e−me^{-m}e−m appears in every numerator and in the denominator, so it cancels while keeping exponent arguments nonpositive.
