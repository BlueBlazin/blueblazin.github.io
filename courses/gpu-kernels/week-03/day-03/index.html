Implement Triton Matmul Tile Loop

By the end of this hour

  • Implement an exact-tile Triton matrix multiplication.
  • Accumulate successive K tiles before storing the result.

Before you begin

  • Your dimensioned matmul tile derivation and precision contract.
  • The pinned NVIDIA/Triton environment and controlled reference.

Environment or workflow question? Day 0 handbook.

The key idea

The tiled kernel maintains an FP32 accumulator with shape BLOCK_M by BLOCK_N. On each K iteration, it loads A with shape BLOCK_M by BLOCK_K and B with shape BLOCK_K by BLOCK_N, applies a matrix dot product, and adds the result to that accumulator. Only after all K chunks have contributed is the accumulator cast and stored. Starting with dimensions that are exact tile multiples removes partial-tile indexing from the first debugging pass. This is a learning implementation: matching the reference and explaining the dataflow matter before tuning or comparing against a library kernel.

Your 60-minute plan

  1. Retrieve

    5 min

    State the shapes of the two input tiles and accumulator. Explain why storing after every K chunk is unnecessary.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Inspect K3’s matmul loop and tl.dot usage for your pinned version. Match supported block sizes and dtypes instead of inventing a hardware-specific path.

  3. Build

    35 min

    Create kernels/triton_matmul.py with a checked wrapper and an explicit two-dimensional output-tile mapping. Use an initial supported configuration such as BLOCK_M=32, BLOCK_N=32, BLOCK_K=32. Allocate an FP32 accumulator, advance A/B pointers through K, and store the final cast result. Test exact-multiple cases such as (M,N,K) = (32,32,32), (64,32,64), and (32,64,96) against the saved reference. Include nonidentical rows and columns to expose transposition errors. Keep the wrapper restricted to the agreed contiguous FP16 contract until this path works.

  4. Verify and save

    10 min

    Save maximum errors for all exact-tile cases. Check a selected output entry against a CPU dot product and explain the K-pointer increments.

What to save

Exact-tile matrix products match the reference.

Watch for: Do not transpose B implicitly in the pointer formula merely because each output is described as a dot product.

Check your understanding

What error occurs if the accumulator is reset inside the K loop?

Check your reasoning

Only the final K chunk contributes to the stored output, so the result is an incomplete dot product.
