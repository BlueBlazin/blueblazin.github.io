Support Matmul Boundaries and Strides

By the end of this hour

  • Handle incomplete M, N, and K tiles correctly.
  • Declare and validate the matrix layout support boundary.

Before you begin

  • The exact-tile Triton matmul from 5-2.
  • Its fixed block sizes and controlled-precision reference.

Environment or workflow question? Day 0 handbook.

The key idea

Matrix multiplication has three independent boundaries. Invalid rows or columns must not be stored, while invalid K positions must contribute zero to the dot product. Mask A loads using both row and K validity, and mask B using K and column validity. An output store uses row and column validity. Strides let one kernel support more layouts, but they are not a promise that every strided view is valid or efficient. A small explicit layout contract is preferable to silently computing incorrect results for a transposed or sliced input. Test each boundary separately before combining them.

Your 60-minute plan

  1. Retrieve

    5 min

    Write the masks for A, B, and C tiles when M, N, and K are not tile multiples.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read K3’s matmul boundary handling. Trace zero-padding in the last K tile and distinguish load masks from output-store masks.

  3. Build

    35 min

    Add masks for the actual M, N, and K dimensions, using zero for invalid A/B load lanes. Keep the output store masked in both output axes. Test dimensions one below, equal to, and one above your tile boundaries; vary M, N, and K individually, then together. Pass real tensor strides to address calculations. Either support and test one simple transposed-input layout or reject noncontiguous inputs explicitly; do not leave behavior accidental. Save a case table naming the dimensions, layout, output error, and whether the wrapper accepted or rejected the input.

  4. Verify and save

    10 min

    Re-run exact-tile cases after adding masks. Verify a case with partial K against the reference and ensure rejected layouts produce a clear error before launching.

What to save

Boundary-shape comparisons pass under the stated layout contract.

Watch for: A passing square-matrix test can hide a swapped row/column stride.

Check your understanding

Why is masking only the output store insufficient for a partial K tile?

Check your reasoning

The dot product would still read invalid A/B values and include them in valid outputs; the reduction’s input loads need masks and zero padding.
