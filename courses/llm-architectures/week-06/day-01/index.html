Trace MLA Projection Tensor Dimensions

By the end of this hour

  • Trace latent and positional projection dimensions.
  • Keep paper notation and one reference implementation aligned.

Before you begin

  • Your GQA diagram, including query and KV head counts.
  • A8 open at the MLA equations and its linked official implementation.

Environment or workflow question? Day 0 handbook.

The key idea

Treat this session as an architecture-reading exercise: the deliverable is a dimensioned trace, not another complete attention implementation. A useful trace records each tensor’s name, symbolic shape, defining operation and role. Keep batch and token axes visible, and distinguish dimensions that are shared across heads from dimensions repeated for every head. Paper notation and code layouts may be transposes of one another. Resolving that difference explicitly is more valuable than copying an equation whose matrix products you cannot check.

Resources for this hour

Read the indicated section, not the entire source. The core reading fits inside the plan below. A video is an alternative to reading, not extra homework.

    DeepSeek-V2: MLA architecture

Your 60-minute plan

  1. Retrieve

    5 min

    Draw your current GQA projection shapes and identify which axes are replicated across query heads.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read A8’s MLA projection equations, concentrating on the joint KV latent and the separate positional component.

  3. Build

    35 min

    Create notes/mla.md with columns for paper symbol, shape, operation and code location. Trace a token representation through the down-projection to the KV latent, the content key/value up-projections, and the positional-key path. Add query content and positional shapes only far enough to form an attention score. Choose the paper’s row- or column-vector convention and use it consistently. Link the exact reference revision you inspect. If a code path fuses projections, describe the mathematical pieces in the note rather than trying to rewrite or execute the whole model.

  4. Verify and save

    10 min

    Verify every product’s inner dimensions and the final score’s scalar shape for one query head and one cached token. Save the partial note with any unresolved symbols marked.

What to save

Dimensioned MLA projection trace recorded.

Watch for: Mixing row-vector code notation with column-vector paper notation can make plausible-looking dimensions inconsistent.

Check your understanding

Why is it useful to keep the positional component separate in a dimension table?

Check your reasoning

It prevents silently counting it as part of every content head or omitting its distinct cache contribution.
