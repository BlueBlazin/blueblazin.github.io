Trace A Single Recurrent Update

By the end of this hour

  • Trace a single gated delta update with consistent dimensions.
  • Explain state decay separately from the targeted delta correction.

Before you begin

  • notes/hybrid-state.md with a selected recurrent component.
  • A9’s gated delta rule equation or its linked reference code.

Environment or workflow question? Day 0 handbook.

The key idea

Use a state matrix S of shape [d_v,d_k], key and query vectors of length dkd_kdk​, and a value vector of length dvd_vdv​. One convenient trace first decays the old state, then corrects its prediction at the new key, and finally reads with the query. This makes every multiplication easy to check. The state matrix is an intermediate memory of the sequence, distinct from the model’s trained projection weights. A dimensioned hand calculation is the required outcome; a full optimized recurrence implementation is not.

Compare State And Cache Scaling

By the end of this hour

  • Count recurrent matrix state independently of sequence length.
  • Calculate combined recurrent and attention state for an illustrative hybrid.

Before you begin

  • The [d_v,d_k] state convention from the previous session.
  • Your full-attention KV formula and hybrid component inventory.

Environment or workflow question? Day 0 handbook.

The key idea

A storage formula describes a representation under stated assumptions. If each recurrent head retains a dvd_vdv​ by dkd_kdk​ matrix, that matrix contributes the same number of elements after ten tokens or ten thousand. This says nothing about how much information can be recovered from it. A hybrid model adds recurrent storage to the KV storage of its attention layers and may retain additional short-convolution state. Keep the matrix-only calculation explicit, then list omitted terms instead of presenting it as exact end-to-end memory.

Check your understanding

Does fixed-size recurrent state imply that arbitrarily long histories can be retrieved exactly?

Check your reasoning
