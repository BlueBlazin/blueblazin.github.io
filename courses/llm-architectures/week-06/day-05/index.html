Before you begin

  • Your KV-cache and MLA state notes.

Environment or workflow question? Day 0 handbook.

The key idea

A hybrid model combines different sequence-processing mechanisms within one network. For this exercise, classify components by the state they retain and the information their next-token computation reads. A recurrent layer updates a bounded state, while a full-attention layer may retain a sequence-length-dependent KV cache. The whole model inherits both kinds of storage. A model-family name is not enough to determine the layer pattern: select one published configuration, record its revision, and trace its actual component inventory before making a scaling claim.

  3. Build

    35 min

    Create notes/hybrid-state.md. Record the exact Qwen3.5 configuration and source revision you inspect. Make a layer-type table with columns for sequence mixer, input/output width, persistent state, and whether that state grows with token count. Use the model card or linked official configuration to identify the pattern; if a dimension is absent, write unresolved instead of guessing. Place the Gated DeltaNet recurrence next to this table as the mechanism you will trace tomorrow. Keep Mamba-2 and Mamba-3 as optional context, not additional required reading or implementations.

  4. Verify and save

    10 min

    Save a small component map and cite the source of the layer pattern. Confirm you have not described the entire hybrid model as constant-memory merely because some layers are recurrent.

What to save

Component map identifies recurrent state and global attention.

Watch for: Do not copy a layer ratio from another model size or family revision without checking the selected configuration.

Check your understanding

Can a model with recurrent layers still have a KV cache that grows with context length?

Check your reasoning

Yes. Any retained full-attention layers can still contribute sequence-length-dependent KV state.
