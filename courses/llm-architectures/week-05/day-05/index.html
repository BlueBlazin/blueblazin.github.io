Implement The Explicit MoE Forward

By the end of this hour

  • Implement weighted top-2 routing on tiny tensors.
  • Preserve autograd through selected routing weights and expert computations.

Before you begin

  • notes/moe-design.md from the previous session.
  • A CPU FP32 PyTorch environment; no GPU session is needed.

Environment or workflow question? Day 0 handbook.

The key idea

The simplest useful MoE forward pass prioritizes readable semantics. Compute router logits, take their top two entries, apply softmax to those two values, then add the two weighted expert outputs. The selected indices are discrete; ordinary autograd does not differentiate the selection boundary. It does differentiate selected logits through their softmax weights and the selected expert computations. Explicit loops are acceptable here because the learning goal is routing correctness. Dispatch efficiency and distributed experts would introduce different engineering problems beyond this lab.

  3. Build

    Implement a small module in your architecture package, using a ModuleList of four experts and one router linear layer. Flatten [B,T,D] into [N,D]. For each token, evaluate only its two selected experts and sum the weighted outputs, retaining tensors rather than converting weights to Python numbers. Stack the results and restore [B,T,D]. Return routing indices and weights as optional diagnostics. Run the six-token fixture, print only shapes and selected expert IDs, and backpropagate a scalar loss to confirm the graph remains connected.

  4. Verify and save

    10 min

    Save the module and a deterministic six-token example. Confirm selected weights sum to one, the output shape equals the input shape, and backward produces finite gradients.

What to save

Forward runs with documented routing and output shapes.

Watch for: An in-place write into a detached output buffer or accidental .item() can silently break the desired gradient path.

Check your understanding

Why does converting a routing weight to a Python float cause trouble?

Check your reasoning

The float is detached from autograd, so that contribution no longer trains the router through the weighted output.
