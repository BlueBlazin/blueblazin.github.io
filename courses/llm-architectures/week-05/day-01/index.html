Prepare Masked SFT And Baseline

By the end of this hour

  • Mask prompt tokens correctly in the supervised loss.
  • Measure baseline syntax validity and task accuracy using a frozen grader.

Before you begin

  • Frozen data, prompt format and split manifest.
  • The pinned base model and adapter initialization that preserves it.

Environment or workflow question? Day 0 handbook.

The key idea

For completion-style SFT, the model sees prompt plus target, but only the target tokens should contribute to the intended training loss. Causal loss shifting makes mask alignment important: the logit at the last prompt position predicts the first target token. Some model libraries perform the shift internally, so labels should follow that interface rather than being shifted twice. Evaluation has two distinct questions: did the output parse and meet the schema, and did its values match the expected answer? A syntactically valid wrong extraction is still a task failure.

Your 60-minute plan

  1. Retrieve

    5 min

    For tokens [prompt1,prompt2,target1,target2], identify which logits predict target1 and target2.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Review the loaded model’s causal-loss interface and the course prompt-masking requirement. Specify exact schema validity and task-accuracy rules before generation.

  3. Build

    35 min

    Build training examples as the fixed prompt followed by the JSON target and chosen terminator. Mask prompt and padding label positions with the library’s ignore value, respecting its internal shift convention. Inspect one token-by-token table manually and verify the first target token contributes to loss. Implement a strict JSON/schema grader and a separate exact-field correctness check, with malformed and valid-but-wrong fixtures. Run the frozen held-out baseline on the pinned base with adapters disabled or restored to their zero-update initialization, using greedy decoding and a short explicit output cap. Decode and grade only newly generated token IDs after the prompt prefix; retain the full token trace separately. Save raw completions and per-example scores without tuning the prompt from these results.

  4. Verify and save

    10 min

    Save the mask table, grader fixtures, decoding settings and baseline validity/accuracy counts with denominator 100.

What to save

Mask checks pass; baseline validity and accuracy saved.

Watch for: Do not shift labels manually if the selected model loss already shifts them internally.

Check your understanding

Why must valid JSON and correct extraction be reported separately?

Check your reasoning

The model can learn the output format while still selecting incorrect values. Separate metrics reveal whether improvement is structural, semantic or both.
