Validate The Modern Dense Decoder

By the end of this hour

  • Integrate RMSNorm, RoPE, SwiGLU and GQA into one decoder.
  • State clearly what “Llama-style” means for this implementation.

Before you begin

  • Individually tested normalization, feedforward, rotary and grouped-attention modules.
  • The earlier GPT checkpoint and regression tests remain available.

Environment or workflow question? Day 0 handbook.

The key idea

A collection of correct primitives can still fail when assembled: position embeddings may be applied twice, masks may use the wrong dimensions, or a reshape may change head ordering. Integration therefore needs both component tests and whole-model invariants. “Llama-style” describes selected architectural ideas, not checkpoint compatibility. Exact compatibility also depends on parameter naming/layout, tokenizer, frequency conventions, normalization constants and other configuration details. Keep this teaching model small enough that every intermediate tensor and failing example can be inspected locally.

Resources for this hour

Read the indicated section, not the entire source. The core reading fits inside the plan below. A video is an alternative to reading, not extra homework.

Your 60-minute plan

  1. Retrieve

    5 min

    List the four architectural changes and one failure that would appear only when they are composed.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Use A2 to make a compact comparison table: your decoder’s component, chosen setting and any difference from the reference architecture.

  3. Build

    35 min

    Create a modern-decoder configuration that uses RMSNorm, SwiGLU, RoPE and GQA together. Remove learned absolute position addition on this configuration so positions are not represented twice accidentally. Run the fixed sample through the full model and repeat the future-token perturbation, rotary identity, grouped-reference and stable-loss tests. Perform only a short repeated-batch training sanity check using your existing loop; do not begin a larger run. Record vocabulary, bias choices, hidden width, rotary layout/base and normalization epsilon in one configuration file.

  4. Verify and save

    10 min

    Save a comparison note and a compact test summary. If the integrated check fails, locate the first divergent intermediate rather than loosening tolerances.

What to save

Integrated decoder passes RoPE, GQA and causal correctness gates.

Watch for: Do not claim Llama weight compatibility merely because the model uses the same named building blocks.

Check your understanding

Why does passing each primitive test not prove the full decoder is correct?

Check your reasoning

The integration can connect correct functions with incorrect layouts, masks, offsets or parameter mappings. Whole-model invariants and intermediate comparisons exercise those connections.
