Apply JAX Transformations To Primitives

By the end of this hour

  • Apply grad, vmap and jit to the same small mathematical function.
  • Explain shape and state constraints exposed by transformations.

Before you begin

  • The pure JAX functions and parameter pytree from the previous session.
  • A small fixed matrix/vector example with an analytic derivative.

Environment or workflow question? Day 0 handbook.

The key idea

JAX transformations change how a function executes while preserving its mathematical intent. grad differentiates a scalar-valued function with respect to chosen arguments. vmap maps a function over designated batch axes without writing the batch loop yourself. jit compiles a traced computation specialized to relevant shapes and static choices. They compose, but a Python side effect is not reliable runtime state. A tiny linear regression example makes expected values and gradients calculable, letting you distinguish transformation mistakes from the complexity of a transformer.

Port Shared Decoder Layer Primitives

By the end of this hour

  • Port modern-decoder primitives into pure JAX functions.
  • Control framework differences using identical NumPy parameters.

Before you begin

  • Tested PyTorch RMSNorm, RoPE, projections and SwiGLU.
  • The JAX transformation exercises and a shared tiny configuration.

Environment or workflow question? Day 0 handbook.

The key idea

Cross-framework parity requires matching mathematics before comparing results. PyTorch linear layers commonly store weights as [out,in], while a direct x@W convention uses [in,out]; either is valid, but the conversion must be explicit. RMSNorm epsilon placement, rotary pairing and activation definitions must also agree. Independently seeded initializations are not equivalent across frameworks, so generate each parameter once in NumPy and load those arrays into both implementations. Begin on CPU FP32 to keep device and mixed-precision differences out of the first comparison.

Your 60-minute plan

  1. Retrieve

    5 min

    Write both linear-weight layout conventions and show the transpose that relates them.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Consult A4 for array operations and broadcasting needed by the primitives. Review your own PyTorch formulas rather than importing a second model implementation.

  3. Build

    35 min

    Write pure JAX functions for linear projection, RMSNorm, RoPE and SwiGLU using the same documented formulas as PyTorch. Generate a deterministic NumPy parameter bundle and input arrays; map them explicitly into each framework. Compare each primitive independently, including zero-position and nonzero-offset RoPE examples. Start with atol=1e-5 and rtol=1e-4 on FP32 CPU, recording actual maximum absolute and relative errors rather than only a pass flag. Do not assemble the full decoder yet; this session isolates the reusable functions.

  4. Verify and save

    10 min

    Save the shared parameter bundle or reproducible generation script and a primitive-forward parity table with shapes and tolerances.

What to save

Shared arrays produce matching primitive forward outputs.

Watch for: A weight transpose can preserve dimensions when a matrix is square, so inspect values and conventions rather than relying on shape alone.

Check your understanding

Why is using seed 42 in both frameworks insufficient for a parity test?

Check your reasoning

Frameworks can use different random algorithms, initialization formulas and draw ordering. Identical seed numbers do not guarantee identical parameter arrays.
