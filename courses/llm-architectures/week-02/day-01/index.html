The key idea

RMSNorm rescales each token vector using its root mean square:

yi=xigi1D∑j=1Dxj2+ε.y_i=\frac{x_i g_i}{\sqrt{\frac{1}{D}\sum_{j=1}^{D}x_j^2+\varepsilon}}.yi​=D1​∑j=1D​xj2​+ε​xi​gi​​.

Unlike LayerNorm, it does not subtract the mean. SwiGLU uses two input projections, multiplies them elementwise, then projects back:

SwiGLU⁡(x)=(SiLU⁡(xWgate)⊙xWup)Wdown.\operatorname{SwiGLU}(x)=\bigl(\operatorname{SiLU}(xW_{\mathrm{gate}})\odot xW_{\mathrm{up}}\bigr)W_{\mathrm{down}}.SwiGLU(x)=(SiLU(xWgate​)⊙xWup​)Wdown​.

The intermediate width is a design choice; copying the old 4C width increases parameter count because there are now three projection matrices. These replacements change the function and parameter budget, so preserve the GPT baseline and record the modern decoder’s exact configuration.

Your 60-minute plan

  1. Retrieve

    5 min

    Write LayerNorm’s centering step and predict what happens if a constant is added to every channel before RMSNorm.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read A2’s descriptions of RMSNorm and feedforward activation choices. Derive the three SwiGLU projection shapes for input width C and hidden width M.

  3. Build

    35 min

    Implement RMSNorm over the final channel axis, with FP32 statistics for low-precision inputs and a learned gain initialized to one. Compare with a direct small-array formula. Implement SwiGLU as gate and up projections of shape C→M, an elementwise product and a down projection M→C. Choose and record M; use approximately 8C/3 only as a parameter-budget starting point, adjusting to an integer. Swap these modules into the pre-norm block and run one loss/backward pass on the existing tiny sample.

  4. Verify and save

    10 min

    Save shape equations, parameter-count changes and tests covering zero input, ordinary random input and finite gradients.

What to save

RMSNorm and SwiGLU have documented shapes and passing smoke checks.

Watch for: Reducing across batch or sequence axes accidentally makes one token’s normalization depend on other tokens.

Check your understanding

Why is an approximately 8C/3 hidden width often a useful comparison with a 4C two-layer MLP?

Check your reasoning

Ignoring biases, the two-layer 4C MLP has about 8C² weights. A three-matrix SwiGLU has about 3CM; setting M≈8C/3 makes those counts similar.
