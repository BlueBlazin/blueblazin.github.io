Compute & budget

A$300 within A$1,000 across all three courses.

Use your M1 Max for small CPU references, PyTorch/JAX parity, data checks and supported MPS experiments. Rent a Linux RTX 4090 only for bounded training or inference measurements; move to an A100 only after a memory pilot shows the need. This course does not require H100. Reserve A$220 for GPU time, A$30 for storage/transfers and A$50 for price, tax and currency variation.

Allowances: architectures A$300, kernels A$450, harnesses A$250. Check current provider prices, currency conversion, taxes and storage charges before paying. Start from a local smoke test, set a job cap and stop idle resources.

Setup and spending checklists are in Day 0. Rent hardware only when the scheduled experiment needs it.
