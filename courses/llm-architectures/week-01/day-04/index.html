Finish The Tiny GPT Model

By the end of this hour

  • Turn the block into a complete tiny decoder.
  • Calculate a parameter count that includes embeddings and the output head.

Before you begin

  • The tested GPT block and input embedding wrapper.
  • A fixed tokenizer vocabulary size V.

Environment or workflow question? Day 0 handbook.

The key idea

A complete decoder wraps repeated residual blocks between input embeddings and a final normalization plus vocabulary projection. The logits retain [B,T,V] so every token position can contribute a training example. Embedding parameters can dominate a tiny model when the tokenizer vocabulary is large, which makes width alone a misleading model-size label. Weight tying reuses the token embedding matrix for the output projection; if you choose it, count the shared parameter once. A tiny configuration is a correctness tool rather than a language-quality demonstration.

Your 60-minute plan

  1. Retrieve

    5 min

    List all parameter-bearing components from token IDs to logits. Predict which component dominates for a large vocabulary.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Inspect the high-level model structure in A1 or A13 only after writing your own component list; focus on final normalization and the vocabulary head.

  3. Build

    35 min

    Create a configuration with two blocks, width 128, a head count dividing 128, and context length 32 or 64. Assemble embeddings, blocks, final LayerNorm and a vocabulary projection. Make the weight-tying choice explicit. Add a forward method that returns logits and optionally the shifted-token loss. Calculate each component’s parameter count by hand or a short formula, then compare with unique trainable tensors. Run the fixed sample, test a shorter sequence, and reject an input longer than the configured position table.

  4. Verify and save

    10 min

    Save the configuration, component parameter-count table and a finite-logit smoke test. Do not change the frozen sample to make the test easier.

What to save

A complete decoder produces finite token logits.

Watch for: Summing aliases separately can double-count a tied embedding/output parameter.

Check your understanding

Why can a “width 128” model still contain millions of parameters?

Check your reasoning

Its token embedding contains V×128V\times128V×128 parameters, and an untied output head adds another similarly sized matrix. Vocabulary size matters even when the residual stack is small.
