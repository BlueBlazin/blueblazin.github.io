Implement And Check Causal Attention

By the end of this hour

  • Implement scaled causal self-attention with explicit shapes.
  • Demonstrate that future tokens cannot affect earlier outputs.

Before you begin

  • Stable-loss tests and the fixed token sample.
  • A chosen tiny shape: B=2, T=8, width=32, four heads.

Environment or workflow question? Day 0 handbook.

The key idea

Each attention head maps a token vector to query, key and value vectors. With Q,K,V shaped [B,H,T,D], scores QKᵀ/√D have shape [B,H,T,T]. The causal mask excludes key positions greater than the query position before softmax. Softmax normalizes over keys, then its weights multiply V. Scaling reduces growth in score variance with head width. A causal model must be invariant to changes strictly after the position being predicted; this behavioral test catches mistakes that a shape test cannot.

Your 60-minute plan

  1. Retrieve

    5 min

    From memory, write the shapes of QKᵀ and attention weights times V. Which axis does softmax normalize?

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read A1 on scaled dot-product attention and causal masking. Sketch an 8×8 allowed-position matrix with the diagonal included.

  3. Build

    35 min

    Implement projections from [B,T,C] to Q,K,V, reshape to [B,H,T,D], apply scaled scores, mask future positions with negative infinity, and normalize over the final axis. Combine heads back to [B,T,C] and apply an output projection. Use plain PyTorch operations so intermediate tensors remain inspectable. On a fixed random input, save the output, change input positions 5 onward, and confirm output positions 0 through 4 are unchanged. Also inspect attention weights to confirm every forbidden entry is zero.

  4. Verify and save

    10 min

    Save a shape table and tests for output shape, row sums and future-token perturbation. Run in evaluation mode with dropout absent or disabled.

What to save

Documented shapes and a passing causal-independence test.

Watch for: A mask with the wrong triangle can still produce finite outputs and correct tensor dimensions.

Check your understanding

Why must the causal mask be applied before softmax?

Check your reasoning

Softmax must normalize only over allowed keys. Zeroing forbidden probabilities afterward without renormalization changes the scale of the remaining weighted sum.
