Implement Stable Next-Token Loss

By the end of this hour

  • Freeze a repeatable tiny token dataset.
  • Implement numerically stable next-token cross-entropy.

Before you begin

  • Day0 readiness is complete: NumPy/PyTorch CPU imports work and the course repository exists.
  • Use the optional Day0 diagnostic only if a prerequisite is rusty; no diagnostic report is required to begin.

Environment or workflow question? Day 0 handbook.

The key idea

A language-model example contains input tokens and targets shifted by one position. If logits have shape [B,T,V], each [V] row predicts the next token; the loss averages valid positions. Stable cross-entropy is log-sum-exp of the logits minus the target logit:

ℓ(z,y)=log⁡∑jezj−zy=m+log⁡∑jezj−m−zy,m=max⁡jzj.\ell(z,y)=\log\sum_j e^{z_j}-z_y = m + \log\sum_j e^{z_j-m}-z_y,\qquad m=\max_j z_j.ℓ(z,y)=logj∑​ezj​−zy​=m+logj∑​ezj​−m−zy​,m=jmax​zj​.

Subtracting each row maximum before exponentiation avoids overflow without changing the softmax distribution. Freezing the input bytes, tokenizer identity and token IDs gives every later framework comparison the same starting point. A small fixed sample is sufficient here; corpus preparation comes later.

Your 60-minute plan

  1. Retrieve

    5 min

    Write the input and target sequences produced from token IDs [4,7,2,9]. State the expected logits shape.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Use A1 to review shifted language-model targets and log-sum-exp. Derive why adding one constant to every logit leaves cross-entropy unchanged.

  3. Build

    35 min

    Use the model/, tests/, data/ and notes/ directories prepared on Day0. Choose and pin one existing tokenizer; do not train a tokenizer in this session. Save a short text sample you can redistribute, its checksum, tokenizer revision and resulting token IDs. Form two fixed examples without crossing document boundaries. Implement cross-entropy using a row maximum and log-sum-exp, gathering target logits before averaging. Compare against PyTorch functional cross_entropy on random logits and on [1000,999]. Keep the reference in the test rather than replacing your implementation.

  4. Verify and save

    10 min

    Check finite loss, translation invariance after adding 1000 to every logit, and agreement with the reference. Save data/manifest.json and the small loss test.

What to save

Fixed sample manifest and matching loss values.

Watch for: Do not shift targets twice when flattening [B,T,V] logits for a framework loss.

Check your understanding

Why is subtracting the maximum legitimate even though it changes every logit?

Check your reasoning

The same exponential factor appears in the softmax numerator and denominator and cancels. Equivalently, the added shift cancels between log-sum-exp and the target logit.
