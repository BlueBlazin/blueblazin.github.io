Load The Small Pretrained Decoder

By the end of this hour

  • Load a pinned small pretrained model and its matching tokenizer.
  • Record a reproducible baseline without claiming custom-model compatibility.

Before you begin

  • A working PyTorch environment and sufficient local memory for a 360M-parameter model.
  • A short fixed prompt and the course compute budget.

Environment or workflow question? Day 0 handbook.

The key idea

Loading pretrained weights adds an external specification: architecture configuration, tokenizer, special tokens, parameter names and revision all matter. The practical baseline here is SmolLM2-360M loaded with its supported model implementation and official tokenizer. This is separate from proving that your teaching decoder can ingest its checkpoint. Pinning an immutable revision makes later before/after comparisons meaningful. A baseline record should include token IDs and decoding settings as well as text, because tokenizer or generation defaults can otherwise change the experiment silently.

Your 60-minute plan

  1. Retrieve

    5 min

    List what must match besides hidden width before one decoder can safely load another decoder’s weights.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read A6’s model card and configuration. Identify whether the selected checkpoint is a base or instruction model and what prompt format it expects.

  3. Build

    35 min

    Load the official SmolLM2-360M checkpoint and matching tokenizer with an immutable revision, recording the framework/library versions and chosen device/dtype. Prefer the M1 Max for this small smoke test if the supported backend works; use CPU for correctness checks when needed. Inspect vocabulary size, special-token IDs, layer count, head counts and maximum context configuration. Tokenize the fixed prompt, run an evaluation forward pass and generate a short capped greedy continuation. Save the actual token IDs and settings. If loading fails, diagnose the exact dependency or memory error within the timebox.

  4. Verify and save

    10 min

    Save a model manifest, parameter count and baseline output. Record the model-card license and avoid storing a duplicate large checkpoint in your Git repository.

What to save

Pinned pretrained model and tokenizer produce a baseline output.

Watch for: Do not apply an instruction/chat template blindly to a base model or assume your teaching decoder is checkpoint-compatible.

Check your understanding

Why is the repository name alone insufficient to reproduce this loading experiment?

Check your reasoning

The repository can change across revisions, and tokenizer files or configuration can change alongside weights. Reproduction needs the exact revision and relevant library and decoding settings.
