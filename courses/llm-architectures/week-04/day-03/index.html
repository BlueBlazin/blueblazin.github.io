Derive And Implement Low Rank Updates

By the end of this hour

  • Derive LoRA’s low-rank update and trainable parameter count.
  • Implement a linear adapter while keeping base weights frozen.

Before you begin

  • A tested PyTorch linear layer and gradient checks.
  • A scratch small-matrix example, separate from pretrained loading.

Environment or workflow question? Day 0 handbook.

The key idea

LoRA represents a weight update as a product of two smaller matrices. For a linear weight W shaped [out,in], choose A shaped [r,in] and B shaped [out,r], then use W_eff=W+(α/r)BA. The base W stays frozen while A and B train, giving r(in+out) trainable weights instead of out×in. This reduces trainable state, but it does not remove the base model’s forward computation or weights. The adapter is still a precisely defined mathematical function whose output and gradients can be tested on small arrays.

Resources for this hour

Read the indicated section, not the entire source. The core reading fits inside the plan below. A video is an alternative to reading, not extra homework.

  • Core · 10 min · paper
    LoRA: Low-Rank Adaptation of Large Language Models

    Low-rank parametrization and scaling; derive factor dimensions.

Your 60-minute plan

  1. Retrieve

    5 min

    For in=8, out=12 and rank=2, compute the base and adapter parameter counts before reading the formula again.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Read A5’s low-rank update construction and scaling. Derive output = linear(x,W)+(α/r)linear(linear(x,A),B).

  3. Build

    35 min

    Implement a small linear wrapper with an existing frozen base weight and optional frozen bias. Store rank and scaling explicitly, create A and B with the documented shapes, and compute the two adapter projections without materializing a full update during ordinary forward calls. Start with in=8, out=12 and rank=2 so the parameter count is easy to inspect. Run a scalar loss backward and inspect which tensors receive gradients. Compare the wrapper’s forward output with a direct dense effective-weight calculation using the same arrays.

  4. Verify and save

    10 min

    Save the formula, parameter-count calculation and forward/gradient checks. Make the freeze assertion part of the adapter test.

What to save

Trainable parameters match the calculated low-rank count.

Watch for: Do not include the frozen base parameters in the optimizer merely because the wrapper exposes them.

Check your understanding

For an 8→12 linear layer at rank 2, how many adapter weights train, excluding biases?

Check your reasoning

There are 2×8+12×2=40 trainable adapter weights. The frozen base matrix contains 12×8=96 weights.
