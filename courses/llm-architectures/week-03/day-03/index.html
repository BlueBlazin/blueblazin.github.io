Match Parameter Layouts Across Frameworks

By the end of this hour

  • Define an auditable parameter conversion between complete models.
  • Localize full-logit differences using intermediate activations.

Before you begin

  • The complete JAX forward function and PyTorch modern decoder.
  • Shared NumPy arrays and established primitive layout conventions.

Environment or workflow question? Day 0 handbook.

The key idea

A full-model parity failure is easier to solve as a sequence of local comparisons than as one large final error. Parameter conversion is a mapping contract: each source tensor has a destination, shape, optional transpose and interpretation. Starting from identical weights, compare embedding output, normalized states, attention output and residual block output in order. The first mismatch narrows the cause. Use identical token IDs, position offsets, masks and evaluation settings, and keep all calculations on CPU FP32 while establishing this baseline.

Your 60-minute plan

  1. Retrieve

    5 min

    Name three non-weight inputs that can cause different logits despite identical parameters.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Review your primitive conversion notes and A4’s array/tree handling. Write the full parameter mapping before implementing it.

  3. Build

    35 min

    Export or generate one shared complete parameter bundle, including normalization gains and tied-weight choices. Build explicit conversion functions for both frameworks and check every destination shape; reject missing or extra parameter names. Run the same tiny token batch through both models while capturing embeddings and each block’s residual output. Compare these in order, then compare final logits with your initial FP32 tolerances. If a mismatch appears, drill into that block’s normalization, Q/K/V layout, rotary values and head grouping instead of changing multiple components at once.

  4. Verify and save

    10 min

    Save the parameter mapping and an intermediate-to-final error table. Demonstrate that re-exporting converted arrays preserves the original values.

What to save

Shared weights yield matching full-model logits.

Watch for: Never silently drop unmatched parameter names during a conversion; this can leave random weights in one model.

Check your understanding

What does it suggest if embeddings match but the first attention output does not?

Check your reasoning

The problem is likely downstream of token lookup and upstream of the attention output: normalization, projection mapping, head layout, rotary positions, masking or attention arithmetic. Inspect that interval first.
