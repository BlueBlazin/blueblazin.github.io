Assemble The Functional JAX Decoder

By the end of this hour

  • Assemble a complete functional JAX decoder from tested primitives.
  • Keep parameters, random keys and configuration explicit at the model boundary.

Before you begin

  • JAX primitive forward/gradient parity tests.
  • The PyTorch modern decoder and its tiny two-layer configuration.

Environment or workflow question? Day 0 handbook.

The key idea

The JAX decoder should implement the same sequence of operations as the PyTorch model, with a different state-management style. A parameter pytree can hold embeddings, a list of block dictionaries, final normalization and the vocabulary head. The forward function receives that tree, token IDs, positions and any needed random key, then returns logits. A short fixed Python loop over two blocks is adequate for this correctness model; introducing advanced scan or sharding abstractions now would add another variable to diagnose.

Your 60-minute plan

  1. Retrieve

    5 min

    Draw the complete modern decoder path and annotate where positions, masks and random keys enter.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Use A4’s pytree and pure-function guidance to decide your model parameter structure. Review the already-tested block equations.

  3. Build

    35 min

    Compose token lookup, RMSNorm, rotary GQA, SwiGLU, residual additions, final normalization and the vocabulary head into a pure forward function. Use a tiny configuration and a fixed causal mask; keep dropout disabled for initial parity. Give each layer a named parameter subtree and validate expected shapes at a wrapper boundary. Pass a positions vector explicitly so later cached decoding conventions remain visible. Run one full forward and scalar loss calculation, returning optional intermediate activations for debugging rather than printing inside transformed code.

  4. Verify and save

    10 min

    Save the complete forward function, a parameter-tree shape manifest and a finite [B,T,V] logits test. Run the future-token perturbation check once.

What to save

Complete decoder runs on the tiny configuration.

Watch for: Do not create or mutate trainable arrays inside the forward function; pass the parameter tree in.

Check your understanding

Must this tiny decoder use lax.scan to count as a functional JAX implementation?

Check your reasoning

No. Functional means state and effects are explicit. A fixed loop over a tiny known layer list can be traced; scan becomes a useful design choice when its control-flow and compilation tradeoffs matter.
