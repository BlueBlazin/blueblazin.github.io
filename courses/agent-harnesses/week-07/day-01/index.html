Build the Frozen Task Manifest

By the end of this hour

  • Freeze task IDs, fixtures, graders, and split membership.
  • Make an explicit bounded decision about the optional external pilot.

Before you begin

  • Passing fixture controls for the private suite.
  • The 24-task manifest and current repository revision.

Environment or workflow question? Day 0 handbook.

The key idea

A task name is not an immutable measurement artifact. This lesson implements the code that connects a task ID to exact fixture and grader contents, split membership, and repository revision. A deliberate fixture change must become detectable. Optional external infrastructure has its setup instructions in Day 0; it is not required for the private study. If it is ready, fix an external subset before seeing outcomes. Otherwise skip that branch and test the private manifest more thoroughly.

  3. Build

    Implement a freeze-manifest builder for all 24 private tasks. Read fixture and grader bytes, calculate content hashes, resolve the repository commit, and record the8/16 split. Use remaining time to test that a changed fixture or split produces a new identity rather than silently reusing the old manifest.
