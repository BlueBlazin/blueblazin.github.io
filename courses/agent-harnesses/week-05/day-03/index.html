Implement Evidence Preserving Context Compaction

By the end of this hour

  • Insert a bounded compact record into model context.
  • Validate evidence pointers and preserve valid tool-message pairs.

Before you begin

  • Use CompactedContext and the budget/activation specification from Activity 8, step 1.

Environment or workflow question? Day 0 handbook.

The key idea

The first compaction implementation can be deterministic and structured; a model-generated summary is optional, not a prerequisite. Preserve the original task and constraints, insert the compact record, and retain recent complete interaction units that fit the remaining budget. Tool calls and their corresponding results belong together so the next model request remains valid and interpretable. Evidence pointers need version context: a line range in a file that has changed may no longer support the recorded claim. Track resolution failures and stale pointers explicitly.

Your 60-minute plan

  1. Retrieve

    5 min

    What breaks if context selection keeps a tool result but removes the tool call it answers?

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Spend 5 minutes on H18: Preserve needed state while compacting. Spend 5 minutes on H9-tools: Keep complete tool-call/result message groups. Stop at the time limit and use the page as a reference while building.

  3. Build

    35 min

    Implement this interface using a deterministic extractor plus the structured fields from yesterday:

    Build the next request from the immutable task/constraints, compact record, and as many recent complete interaction units as fit. Use the model tokenizer when available; otherwise label the conservative counting method and leave a margin. Add a pointer resolver for event ids and file-version/range references. Mark stale or missing pointers rather than silently treating them as evidence. Test one long synthetic development trace that crosses the activation threshold and includes a changed file. Treat an assistant turn containing multiple tool calls and all corresponding results as one complete interaction group, preserving any provider-required continuation blocks. If fixed content plus the required newest group cannot fit, return an explicit context-budget stop; do not split the group or loop forever.

  4. Verify and save

    10 min

    Save the original and compacted message payloads, token counts or labeled estimates, and pointer-resolution report. Verify every retained tool result has its matching call.

What to save

Compacted example retains all required fields.

Watch for: Do not delete the full event history merely because the model-visible history has been compacted.

Check your understanding

Why include a file version with a line-range evidence pointer?

Check your reasoning

Edits can change line numbers or the content at those lines. The version identifies which snapshot supported the claim and lets the harness detect stale evidence.
