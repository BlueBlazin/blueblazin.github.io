Compute & budget

A$250 within A$1,000 across all three courses.

Use the M1 Max for harness development and deterministic tests. No rented GPU is required. Budget A$175 for model API experiments, A$50 for isolated CPU environments/storage and A$25 for price, tax and currency variation. Use explicit per-run request, token, time and monetary caps before launching paid trials.

Allowances: architectures A$300, kernels A$450, harnesses A$250. Check current provider prices, currency conversion, taxes and storage charges before paying. Start from a local smoke test, set a job cap and stop idle resources.

Setup and spending checklists are in Day 0. Rent hardware only when the scheduled experiment needs it.
