Run The Optional Frozen External Pilot

By the end of this hour

  • Apply the optional external-pilot gates honestly.
  • Keep external results separate from the required private study.

Before you begin

  • A frozen ten-task external subset, or the earlier explicit skip decision.
  • The remaining budget and complete required private-study analysis.

Environment or workflow question? Day 0 handbook.

The key idea

The external pilot is optional and answers a limited portability question. It is not a replacement for the required private experiment and is not a leaderboard score. Run it only if infrastructure was already validated, ten tasks were frozen before outcomes, the same conditions can be compared fairly, and money remains under the course allowance. Otherwise the best use of this hour is deeper analysis of the completed private study. A recorded skip is a valid outcome; rushed setup and post-hoc task selection are not necessary.

Your 60-minute plan

  1. Retrieve

    5 min

    List the gates for the optional pilot and the planned number of attempts if all gates pass.

  2. Study

    10 min

    Use the core resources above for ten minutes in total, focusing only on the indicated sections. Spend 5 minutes on H7-results: Inspect results from the already-frozen optional pilot. Spend 5 minutes on H4: Private-study failure analysis when the pilot is skipped. Stop at the time limit and use the page as a reference while building.

  3. Build

    35 min

    Check the pre-frozen ten-task manifest, compatible harness adapter, immutable benchmark revisions, remaining budget, and per-trial limits. If every gate passes, launch one trial per task and condition for twenty attempts, capture raw traces and usage, and label the output “small-subset external pilot.” Keep bounded jobs in the background as needed. If any gate fails, record the reason and spend the build block extending the private analysis with one additional representative trace or a clearer cost breakdown. Do not install new infrastructure or select replacement tasks based on outcomes.

  4. Verify and save

    10 min

    Save either the twenty-row pilot status/results table or a documented skip plus the improved private-study artifact.

What to save

Twenty external attempts or documented skip.

Watch for: Do not use today to restart the optional installation work that was capped in Activity 10.

Check your understanding

Does a strong result on ten selected external tasks establish benchmark-wide performance?

Check your reasoning

No. It is a small-subset pilot with limited coverage and potentially different execution conditions; report the subset and limitations explicitly.
