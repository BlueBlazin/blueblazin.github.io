CUDA kernel

GPU & numerical code · GPU routine

A CUDA kernel is a GPU entry-point function. A launch specifies a grid of thread blocks; thread indices let each invocation work on a different portion of the input.

i=blockIdx.x⋅blockDim.x+threadIdx.xi=\text{blockIdx.x}\cdot\text{blockDim.x}+\text{threadIdx.x}i=blockIdx.x⋅blockDim.x+threadIdx.x

Example

For vector addition, each in-range thread computes c[i]=a[i]+b[i]. A bounds check handles a final partially used block.

__global__ void add(const float* a, const float* b,
                    float* c, int n) {
  int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i < n) c[i] = a[i] + b[i];
}
// Device pointers assumed; n > 0.
add<<<(n + 255) / 256, 256>>>(a, b, c, n);

The routine can compute any supported operation. It need not be a convolution or an ML similarity kernel.
