A

Gaussian is a shape, not one meaning.

Blur mixes pixels. KDE estimates a density. Heat flow spreads an impulse. An RBF kernel compares inputs. Similar formulas play different roles.

local weights · density bumps · propagator · similarity
B

A graph kernel can be a set or a function.

A digraph kernel is an independent, absorbing vertex set. A graph ML kernel is a pairwise function comparing graph objects.

K ⊆ V   versus   k(G, H) ∈ ℝ
C

Two kernels can belong to one operator.

An integral kernel K(x,y) specifies T. The kernel of T is the set of functions sent to zero. Knowing one does not make them the same object.

representation of T   versus   nullspace of T
D

“The kernel accepted it” has a scope.

Lean’s kernel checks a proof term against a formal proposition under declared assumptions. People must still check that proposition’s intended meaning and its axioms.

formal checking · specification review
E

A Markov kernel need not be an SVM kernel.

A transition matrix has nonnegative rows summing to 1. A PSD kernel must give symmetric positive-semidefinite Gram matrices. Neither requirement implies the other.

probability transition   versus   feature inner product
F

Small core, different job.

An OS microkernel manages isolation and communication. A BLAS microkernel computes a small matrix tile. The prefix describes size, not a shared architecture.

system mechanisms   versus   numerical inner loop

About the taxonomy

A map of meanings, not a claim of finality.

This atlas surveys established uses across STEM, including a few historical and less-common meanings. The families group concepts by what the kernel is or does; they do not assert a shared etymology or historical descent.

Some entries are distinct senses; others are named kernels, software architectures or specializations. Those are labeled, and variants are grouped where separate entries would add little.

Connections cross family boundaries. A heat kernel can be an integral kernel and a transition density. A Bergman kernel is both an integral representation and a reproducing kernel. Placement is a reading aid, not an exclusive classification.

No finite catalogue can guarantee every local coinage, every paper-specific kernel or every future variant. The source list makes the coverage inspectable. Formulas state conventions where needed; simplified and schematic examples are identified.
