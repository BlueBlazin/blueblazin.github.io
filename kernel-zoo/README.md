# Kernel — Forms of One Word

An interactive field guide to the word *kernel*, published at <https://blueblazin.github.io/kernel-zoo/>: a dark cabinet of 103 specimens in eight families.

Entries are filed by **what kind of thing the kernel is** (seed, core, routine, weighting, similarity,
vanishing, remnant, plus one odd one out), using the catalog's `semanticFamily` field.
Every specimen is a single hand-tinted engraving of an object whose anatomy stands for the idea.
For example, Linux is a heart that everything flows through, CUDA is a bee in every cell, and the nullspace is a poppy pressed flat.
The engravings are generated with transparent backgrounds (keeping cream paper only inside each figure) so they float on the near-black page.

Each plate is a spread:

- **verso:** four of its specimens arranged as one engraved plate;
- **recto:** a working figure built from engraved sprites (rings that come away from a walnut, bees filling a comb,
  a magnifying glass weighting pebbles, shells compared bead by bead, beads folding into a brass ring, a lantern
  on a carpet that sees every wall);
- **figurae:** the tray of specimens. Click any of them for its full entry.

## Files

- `index.html`, `style.css`, `app.js`, `plates.js`: the page.
- `data.js`: generated by `_source/build.py` from `_source/catalog.json`; do not edit.
- `img/`: plate engravings, `sp/` one per specimen, `sprites/` pieces for the figures (transparent WebP).
- `_source/specimens.py`: the object behind each specimen, and the shared engraving style.
- `_source/sprites.py`: the sprite subjects. `_source/gen_images.py` holds the plate subjects.
- `_source/analogies.md`: the specimen list in readable form.
- `_source/text/out_*.json`: the card text (definition, explanation, formula and its reading, example,
  why "kernel", caution, variants), in American English for a STEM undergraduate. `build.py` merges it
  over the original catalog text. `_source/text/STYLE.md` is the writing guide it follows.

```sh
python3 _source/build.py                      # rebuild data.js
python3 _source/samples.py linux cuda         # try a few subjects first (writes _source/samples/)
python3 _source/gen_images.py specimens       # generate whatever is missing (needs OPENAI_API_KEY, or an API_KEY file here)
python3 _source/gen_images.py cuda --force    # regenerate particular items
python3 _source/optimize.py                   # trim and convert new PNGs into img/
python3 -m http.server 8765
```
